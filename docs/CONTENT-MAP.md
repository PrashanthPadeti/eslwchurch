## 4. Scripture attribution — a real compliance point

Your quotations are **NIV** throughout, except *Numbers 6:24* which is **KJV**
("bless thee, and keep thee").

The NIV permits quotation up to 500 verses without written permission, provided a
copyright notice appears. You are far under that limit, but the notice is still
required. I will add a standard credit line to the site footer and note the KJV
verse separately.

**Question:** is the mixed translation deliberate? The KJV blessing is a common
and lovely choice for a benediction, so I have assumed yes and will keep it — but
flag it if you would prefer consistency.
